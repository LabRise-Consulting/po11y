## Signing

Open your pull request as normal. A bot will comment asking you to sign, and a
status check will stay red until you do.

Reply to the pull request with exactly this text, as its own comment:

```
I have read the CLA Document and I hereby sign the CLA
```

Your signature is recorded once, against your GitHub account, in
`signatures/version1/cla.json` on the `main` branch. Every pull request you
open after that passes the check automatically. You never sign again.

If the check does not update after you sign, comment `recheck` to re-run it.
